# 🧩 Interview Questions – OOP + TypeScript + Design

### TypeScript & OOP
1. What’s the difference between an interface and an abstract class?
2. How do access modifiers improve encapsulation?
3. What are the advantages of inheritance vs. composition?
4. Explain polymorphism with an example.
5. How does TypeScript enforce type safety in classes?

---

### System Design (HLD)
1. How would you scale this Task Engine for multiple users?
2. What would be your approach to scheduling tasks at exact times (cron-like)?
3. How would you handle failed or retried tasks?

---

### Low-Level Design (LLD)
1. Design a `TaskQueue` that supports prioritization.
2. How can you decouple logging from task execution?
3. How would you make `TaskScheduler` thread-safe or distributed?

---

### Behavioral / Leadership
1. How would you mentor a junior who keeps coupling logic tightly between classes?
2. How would you review this project in a PR for clarity and maintainability?
